# Student Management System

## Project Description
This project is a simple Student Management System developed using Python and Tkinter GUI.  
It allows users to manage student records using file handling.

## Features
- Add Student
- Remove Student
- Search Student
- View All Students
- Remove All Students

## Technologies Used
- Python
- Tkinter
- File Handling

## Files Included
- python_project.py
- Dataset.txt
- GUI Output Image
- Dataset File Output Image

## Output
The project stores student records in a text file and displays them using GUI.
